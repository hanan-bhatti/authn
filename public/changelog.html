v1.0.0 2025-11-06
🎉 Initial Public Release

The first stable release of Authn — a comprehensive authentication system with enterprise-grade security features, full documentation, and a polished developer experience.

✨ Added — Authentication & Security
  • Email/password registration with bcryptjs hashing (12 salt rounds)
  • Login with username or email, "Remember Me" (30-day sessions)
  • JWT-based stateless authentication with configurable expiration
  • Password reset flow with secure single-use tokens (30 min expiry)
  • Email verification with 6-character alphanumeric OTP (10 min expiry)
  • Google OAuth 2.0 via Firebase Admin SDK
  • TOTP-based 2FA with QR code setup, 8-digit backup codes, and progressive lockout
  • Session-based 2FA verification with 5-minute grace period
  • Device fingerprinting — browser, OS, IP, geolocation, unique SHA-256 device ID
  • Trusted device workflow with 24-hour verification tokens and email alerts
  • Up to 5 concurrent sessions per user; individual and bulk revocation
  • Global rate limiting (1 000 req / 15 min) and auth limiting (5 req / 15 min)
  • Progressive account lockout — 30 min after 10 failed logins
  • Helmet security headers — CSP, XSS protection, Clickjacking, MIME sniffing
  • CORS with whitelist-based origin control
✨ Added — User Management
  • Full user profiles: name, username, email, phone, bio, website, location
  • Avatar upload with Sharp processing — thumbnail, small, medium, large in WebP
  • IPFS / S3 storage via Filebase
  • Account deletion with mandatory pre-deletion backup + data anonymisation
  • Account recovery within grace period
  • GDPR-compliant complete data export
  • 4-tier RBAC: user → moderator → admin → superadmin
  • Granular device-level permission tracking (location, camera, microphone, notifications)
  • Language, timezone, theme (light/dark/auto), notification, and privacy preferences
✨ Added — Monitoring & Data
  • Audit logging for all security events (last 50 entries, includes IP + user agent)
  • User analytics: session counts, durations, device counts, login history
  • In-app notification system (last 20 notifications, unread count)
  • Automated backup system with AES-256 encryption and Gzip compression (365-day retention)
  • Scheduled cleanup via node-cron — expired sessions, stale tokens, old backups, unused devices
✨ Added — UI & DX
  • Modern auth pages: login, register, email verification, password reset, 2FA, device verification
  • Full user dashboard with security centre, session manager, and audit log viewer
  • Dark mode, smooth animations, responsive design
  • RESTful API with consistent ApiResponse / ApiError format
  • Input validation via express-validator; standardised error codes
  • ESLint configuration, Nodemon dev server, comprehensive README and API docs
🔄 Changed
  • Migrated Google OAuth verification to Firebase Admin SDK for better security
  • Service-oriented architecture refactor
  • Consistent error responses across all endpoints using ApiResponse
  • Enhanced device fingerprinting with geolocation support
  • Optimised session management
🐛 Fixed
  • Duplicate sessions bug in concurrent login scenarios
  • Timezone issues in token expiration calculation
  • Email template rendering on some SMTP servers
  • Race condition in 2FA backup code usage
  • CORS issues with certain frontend frameworks
🔒 Security
  • bcryptjs 12-round password hashing
  • Timing-safe password comparison
  • CSRF protection for state-changing operations
  • Progressive account lockout
  • Secure token generation for password reset
  • Device fingerprinting for anomaly detection
