Features

Everything you need for auth

Battle-tested authentication primitives so you can focus on building your product, not your auth stack.

🔑
Email / Password Auth

bcryptjs with 12 salt rounds, strong-password enforcement, timing-safe comparison, and secure reset flows.

🛡️
Two-Factor Authentication

TOTP (RFC 6238) compatible with Google Authenticator, Authy, and 1Password. Backup codes included.

🌐
Google OAuth 2.0

Firebase Admin SDK integration. One-click social sign-in with automatic account linking.

📱
Device Management

Browser fingerprinting, trusted device registration, new-device email alerts, and up to 10 devices per user.

🗂️
Session Management

Up to 5 concurrent JWT sessions. View, revoke, or nuke all sessions from any device.

⚡
Rate Limiting

Multi-layer DDoS protection — 5 auth attempts per 15 min, 1 000 API requests per 15 min, per-user throttling.

🔒
RBAC Permissions

4-tier role hierarchy (user → moderator → admin → superadmin) with granular permission inheritance.

📊
Audit Logging

Every security event captured — login, logout, password change, 2FA toggle, device events — with IP & user agent.

💾
Automated Backups

Pre-deletion backups mandatory. AES-256 encryption, Gzip compression, 365-day retention, scheduled via node-cron.

📧
Transactional Email

OTP verification, password reset, security alerts, device notifications — all via Nodemailer.

🖼️
Profile & Avatars

Full user profiles with avatar upload, Sharp image processing, WebP conversion, and IPFS/S3 storage.

📦
GDPR Compliance

Full data export, account deletion with data anonymisation, and preference management built in.

Quick Start

Up and running in minutes

Clone, configure, and launch — no cloud account required.

bash 
# 1. Clone the repo
git clone https://github.com/hanan-bhatti/authn.git
cd authn

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env
# Edit .env with your MongoDB URI, JWT secret, SMTP credentials…

# 4. Start the server
npm start     # production
npm run dev   # development (nodemon)
bash 
# Build & run with Docker Compose
git clone https://github.com/hanan-bhatti/authn.git
cd authn
cp .env.example .env

# Edit .env, then:
docker-compose up -d

# The API is available at http://localhost:5000
